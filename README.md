# Alocca — Downloads

Instaladores oficiais do Alocca para Android e Windows.

## Última versão

[Baixar a versão atual](https://github.com/danilloFranklin/alocca-releases/releases/latest)

Na página da release, escolha o APK para Android ou o arquivo Windows-Setup.exe para instalar no Windows. O ZIP Windows-portatil.zip deve ser extraído por inteiro antes de abrir contratos_sitio.exe.

O arquivo SHA256SUMS.txt permite conferir a integridade dos downloads. Instale a atualização sobre a versão anterior e entre com a mesma conta.

Este repositório distribui somente instaladores e informações de atualização. O código do produto é mantido em repositório privado. Apenas a release mais recente é mantida disponível.
